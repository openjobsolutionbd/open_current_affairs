# archive-staging/standalone/ — ম্যাগাজিন-স্বতন্ত্র কনটেন্ট স্টেজিং

এই ফোল্ডার সেইসব প্রবন্ধ/কনটেন্টের জন্য যেগুলো "প্রফেসর'স কারেন্ট অ্যাফেয়ার্স"-এর মতো কোনো মাসিক ম্যাগাজিন-স্ক্যানের অংশ না — ব্যবহারকারী সরাসরি টেক্সট/ফাইল হিসেবে দেন। মূল `archive-staging/YYYY-MM/` কাঠামো (ম্যাগাজিন পেজ-নম্বর ভিত্তিক) থেকে ইচ্ছাকৃতভাবে আলাদা রাখা হয়েছে, যাতে দুই ধরনের সোর্স মিশে না যায়।

## ফোল্ডার কাঠামো

```
archive-staging/standalone/
  README.md              ← এই ফাইল
  2026-08/                ← জমা দেওয়ার মাস অনুযায়ী (ম্যাগাজিন issue না — শুধু organizational)
    STATUS.md             ← এই মাসে জমা হওয়া সব প্রবন্ধের স্ট্যাটাস ট্র্যাকার
    gorom-o-bojropat.md
    ...
  2026-09/
    STATUS.md
    ...
```

**কেন মাসভিত্তিক ভাগ:** প্রবন্ধ একটা একটা করেও আসতে পারে, ব্যাচেও আসতে পারে (সংখ্যা অনিশ্চিত) — মাসভিত্তিক ফোল্ডার দুই ক্ষেত্রেই STATUS.md ছোট ও ম্যানেজেবল রাখে, এবং future-এ অনেক প্রবন্ধ জমলেও এক ফাইলে সব গাদাগাদি হবে না।

## নতুন প্রবন্ধ যোগ করার নিয়ম

1. বর্তমান মাসের ফোল্ডার না থাকলে তৈরি করুন (`archive-staging/standalone/YYYY-MM/`)।
2. ফাইলনাম বিষয়ের স্লাগ অনুযায়ী (`[a-z0-9]+(-[a-z0-9]+)*`, docs/topics/-এর নিয়মের সাথে সামঞ্জস্যপূর্ণ)।
3. frontmatter:
   ```markdown
   ---
   issue: standalone-YYYY-MM
   source: "ব্যবহারকারীর সরাসরি টেক্সট/ফাইল (ম্যাগাজিন স্ক্যান না)"
   status: pending
   notes: ""
   ---
   ```
4. কনটেন্ট verbatim বসান — কোনো সংযোজন/বিয়োজন/সংশোধন ছাড়া (STAGING_GUIDE.md-এর কঠোর নিয়ম এখানেও প্রযোজ্য: অনিশ্চিত অংশ থাকলে অনুমান করবেন না)।
5. সেই মাসের `STATUS.md`-এ সারি যোগ করুন, `status: pending`।
6. ব্যবহারকারী কনফার্ম করলে `pending` → `confirmed` (ফাইল ও STATUS.md দুই জায়গাতেই)।
7. **এই ধাপে `docs/`-এর কিছু ছোঁয়া হবে না** — গন্তব্য-নির্ধারণ (কোন টপিকে যাবে/নতুন টপিক হবে কিনা) শুধু প্রসেসিং সেশনে, STAGING_GUIDE.md-এর ধাপ ৪ অনুযায়ী।

## STATUS.md ফরম্যাট (প্রতি মাসে একটা)

```markdown
# YYYY-MM — স্বতন্ত্র কনটেন্ট স্টেজিং ট্র্যাকার

| ফাইল | বিষয় | স্ট্যাটাস | নোট |
|---|---|---|---|
| slug-name.md | সংক্ষিপ্ত বিষয় | pending/confirmed | |

**পরবর্তী ধাপ:** সব `confirmed` না হওয়া পর্যন্ত প্রসেসিং শুরু হবে না।
```

## প্রসেসিং

সব প্রবন্ধ `confirmed` হওয়ার পর ব্যবহারকারী "এই মাসের স্বতন্ত্র কনটেন্ট প্রসেস করো" বললে STAGING_GUIDE.md-এর প্রসেসিং সেশন (ধাপ ৪-৫) অনুযায়ী এগোনো হবে — প্রতিটা প্রবন্ধ existing টপিকে merge হবে নাকি নতুন টপিক হবে তা `check_topic.sh` দিয়ে যাচাই করে ঠিক করা হবে।
